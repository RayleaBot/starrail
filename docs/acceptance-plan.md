# 验收与交付计划

本计划承接主仓库 RayleaBot 的游戏插件返工计划中尚未完成的 R7 阶段（验收与交付）；R0 至 R6c 已完成，其内容随主仓库文档删除，不再保留。记录日期：2026-10-02。

## 验收口径

- 用户可见功能以 Windows 实例上的 Core、真实账号和真实聊天消息验收，并与上游同一命令的输出对照；合成数据测试只用于回归，不能替代验收。
- 对照的上游仓库与固定提交见 [DATA_SOURCES.md](../DATA_SOURCES.md)，下文括号内写上游页面或模块名。
- 与上游有意不同的行为见文末一节，对照时不算缺陷。
- 验收结束时提交本仓库，不推送。

## 受限事项

- 国服官方抽卡同步：米游社换取的 AuthKey 被国服接口以 -100 拒绝（成因待验收时核对），国服跃迁记录以聊天发送的链接或 UIGF/SRGF 导入更新；五星摘要不伪装为逐抽明细。
- 星铁官方小程序的五星与卡池摘要同样返回 -100：来源为 Axiu，不在点名范围，国服抽卡恢复后再评估。

- 海外账号与区服：未验收。

## 与上游的有意差异

- 使用专属前缀并关闭通用前缀，命令名不带游戏名；`*帮助` 由插件出图。
- 跃迁写法按 StarRail-plugin、miao（视为强制开启）、Yunzai 的先后分流，每个写法只对应一张图；Yunzai 的“角色统计”“武器统计”按“池统计”改写后再匹配。
- 群排行在群内查看面板时自动登记，没有提交排行与退出排行。
- 不提供上游没有的周期活动、互动、聊天中的体力推送（管理页保留）、保存月报、图鉴图、自动同步、同步进度、停止同步、同步抽卡、“开拓力”写法与“空格加期数”写法。
- `*更新跃迁记录` 按上游在原聊天回复结果，不带全量与增量参数；记录按所指定、当前使用或被 @ 用户的 UID 读取档案，不按 CK 隐藏。
- 8010 按 miao 角色索引名为“星·欢愉”；`*常规演算二<UID>` 按所写条数（上游退回第一条）；ark 文字用“遗器”，命令同时接受“圣遗物”与“遗器”。
- CK 与 SToken 只经扫码登录或管理页加密导入；聊天中出现凭据时提示撤回。
