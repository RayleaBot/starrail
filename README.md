# 崩坏：星穹铁道插件

独立的 RayleaBot Go/Vue 插件，要求包含通用插件服务能力的 Core。游戏增强直接在本插件内实现；账号使用独立的米游社账号插件。

## 当前能力

- 通过 `accounts` v1 共用一次米游社登录，读取已授权角色并选择默认 UID；游戏插件不持有 CK。
- 基础信息、实时便笺、角色列表与基础角色详情；当前主要挑战的摘要和已适配队伍记录。
- `*卡片`（`*探索`、`*角色` 等价，可带 UID）按 StarRail-plugin 的卡片页出图：手机主题背景上的头像、昵称、等级、区服与 UID，活跃天数、已解锁角色、成就、战利品与忘却之庭进度，以及官方卡片列出的角色。
- 按固定参考版本提供 278 条离线角色、装备等资料，支持查询和自定义别名。
- 没有 CK 也可 `*绑定uid<UID>` 绑定 UID，`*uid` 列出、`*uid<序号>` 切换、`*删除uid<序号>` 删除。
- 命令中 @ 他人时读取对方当前使用的 UID，如 `*跃迁分析@某人`、`*希儿面板@某人`；只读取已保存的记录、面板与展柜，不使用对方账号。
- 面板按 UID 保存在本地：`*更新面板 [UID]` 读取 Mihomo 展柜，`*米游社更新面板` 读取本人账号的全部角色，`*面板列表` 按 miao profile-list 出图，`*删除面板<UID>` 删除本人 UID 的面板，`*遗器列表` 按 miao artis-list 列出评分最高的 28 件，`*希儿换满命换满行迹` 等按 miao 的写法换装后重新计算面板；`*希儿面板` 等先读保存的面板，没有时读取本人账号或展柜。
- 私聊或群聊发送游戏内跃迁记录页的链接，按 Yunzai 读取全部卡池（含联动池）的记录并按其抽卡记录页出角色跃迁的图，无需账号；链接的 UID 成为当前使用的 UID，群聊中提示撤回。按 StarRail-plugin，`*抽卡链接` 提示发送链接，`*更新跃迁记录` 用本人一天内发送过的链接重新读取（同一 UID 一小时一次）。链接只保存在内存中，记录较多时转入后台继续读取，完成后在原聊天回复。
- 跃迁的写法按 Miao-Yunzai 中各插件的先后出图，每个写法只对应一张图：StarRail-plugin 规则收下的 `*跃迁记录`、`*角色分析`、`*光锥记录`、`*抽卡统计`、`*角色统计` 等（开头相符即可）按其跃迁分析页出图；其余先按 miao（Miao-Yunzai 强制开启其“抽卡统计”开关）：`*喵喵抽卡记录`、`*喵喵光锥记录`、`*角色池记录`、`*抽奖记录`、`*up记录` 等按 miao 的抽卡分析页，`*喵喵抽卡统计`、`*喵喵角色统计`、`*全部统计`、`*up统计`、`*角色池统计`、`*版本统计` 等按 miao 的抽卡统计页出图；再其余按 Yunzai：`*全部记录`、`*角色联动记录`、`*光锥联动记录`、`*新手池记录` 等按 Yunzai 的抽卡记录页统计所选跃迁的抽数、五星与出金抽数，“全部”依次列出角色、角色联动、光锥、光锥联动与常驻跃迁；`*新手池统计` 等按 Yunzai 的抽卡统计页列出每期卡池的抽数与所得四星、五星及次数，群聊中只列约十二行。
- 按 Yunzai 的写法在聊天中导入导出跃迁记录：`*导入记录` 后两分钟内发送 UIGF v4 或 SRGF 文件（或文件的 https 链接），按记录 ID 去重合并；`*导出记录` 发送当前 UID 的 UIGF v4 文件，`*导出记录v2` 发送 SRGF v1.0 文件。群聊中需写作 `*强制导入记录`、`*强制导出记录`，收到文件后提示撤回。大整数记录 ID 保持原样，原始本地时间不转换；文件缺少的名称、类型与星级按固定资料补全，导入失败不改变已有档案。
- 独立的游戏查询、资料图鉴、抽卡档案、体力提醒与面板历史管理页，聊天结果优先渲染图片，渲染不可用时回退文本。

命令以 `info.json` 的实际声明为准，使用本插件的专属前缀，不响应宿主的通用前缀：默认 `*`、`＊`、`星铁`、`星轨`、`崩铁`、`星穹铁道`、`铁道`、`sr`，管理员可在插件配置的 `command_prefixes` 中修改。下文以 `*` 为例，`*体力` 与 `星铁体力` 等价；`*树脂`、`*查询体力` 同 Yunzai 的写法，也查询体力。上游允许 UID 紧跟在命令后的写法（如 `*深渊100000001`）同样可用，与用空格分开相同。公开资料、公开 UID 展柜和管理页中的历史抽卡档案可在未安装账号插件时使用。聊天中的跃迁记录与上游相同，读取所指定 UID 或当前使用的 UID（含未绑定账号的 UID）的档案。

- 星铁官方暂不接受米游社换取的完整抽卡 AuthKey，账号的后台同步与自动同步因此不可用，跃迁记录以聊天发送的链接或 UIGF/SRGF 导入更新；五星摘要不伪装为逐抽明细。

## 官方查询扩展

开拓月历、异相仲裁、模拟宇宙/蝗灾/黄金/不可知域/差分宇宙、货币战争。`*月历`（`*收入`、`*月收入`、`*星琼获取`、`*原石` 等价）按 StarRail-plugin 的月历页出图；`*星琼` 按 Yunzai 的开拓月历页出图，可接月份（`*星琼7月`、`*星琼七月`），与上游一样只能查本月与前两个月，查询后同上游保存官方仍提供的月份。`*星琼记录`、`*古老梦华记录`、`*体力记录`、`*遗器记录`（可加页码）按 StarRail-plugin 出图查看获取记录，`*在线时长` 由开拓力回复推算近期在线时长。`*货币战争`（`*货币`、`*币战` 等价）与 `*货币战绩`（`回顾`、`战报`、`记录` 等价，可接一至十查看第几条）按 StarRail-plugin 的货币战争页与战绩回顾页出图。跃迁摘要适配器已实现，但当前账号仍被官方活动认证拒绝，保留明确受限状态。

可在游戏查询页选择对应业务，或使用 `info.json` 中声明的命令。月份省略时读取官方默认月份，可填 YYYYMM。挑战期数 1 为本期、2 为上期；模拟宇宙另有 3 的接口默认范围，异相仲裁的 3（往期）为最近三期并排。“深渊”把同一期的混沌回忆、末日幻影与虚构叙事并排出图，“最新深渊”按上游的两周轮换查询最近开启的一种。聊天中的挑战与模拟宇宙命令同 StarRail-plugin 在整条消息中找“上期”与“简易”，写在命令名前后或以空格分开都可以：`*上期深渊`、`*深渊上期`、`*深渊 上期` 相同，`*异相仲裁往期` 并排最近三期（“往期”只用于异相仲裁），模拟宇宙不写期数时查询本期。`*简易深渊`（或 `*深渊简易`）只读取官方的简易记录，照同样的页面出图。

实际账号已验证可用只读端点及相关期次参数，未参与玩法的丰富历史记录仍需继续验收。受限功能保留在完整目标中。

## 详细面板与评分

角色面板展示官方属性、装备词条、技能及星魂；管理页可展开效果说明。可输入角色名称/ID，留空显示轻量角色概览。

使用 `*希儿遗器 [UID]`（也可写 `*评分 希儿`），管理页也可计算。评分与伤害先读本地保存的面板，没有时读取本人账号的官方面板并保存；权重按上游规则随角色当前属性、星魂与配装自动选择。缺少必要数据的装备不评分。评分不是完整伤害计算。

## 角色自动计算与光锥换装

发送 `*希儿伤害 [UID]`，或在角色面板下点击“读取并自动计算”，查看固定参考情境中的角色、光锥和套装增益。管理页可选择候选光锥、等级、突破和叠影，比较期望或暴击值。基准与候选均重新读取当前授权面板；试算不改变游戏装备。`*希儿伤害` 可带序号（如 `*希儿伤害3`），按 miao 的伤害页出图：伤害表带序号，另附所选伤害的词条伤害计算与 Buff 列表。

半血、满层、击杀等条件来自每条参考规则，展开情境可查看增益和适用技能。支持明确未装备状态；缺失必要数据时拒绝计算。可从同账号另一角色调入整套遗器，与候选光锥一起试算。可编辑队伍与条件并保存预设；完整实战对照仍需按具体账号验收。

## 记录与体力提醒

- 抽卡档案的“查看统计”提供按池、稀有度、日期和物品筛选的分页明细，以及月份、物品分布和完整间隔均值；未知稀有度不输出确定保底，档案变化后重新从第一页读取。
- “面板历史”页面主动读取并保存官方角色面板，每个角色最多 20 份，可查看、比较属性/配装/技能、导出或移除。保存时间与资料版本一并展示；撤销账号授权后不能继续访问历史。
- “体力提醒”页面选择账号、阈值和期限，确认后开启每十分钟检查。只私聊账号所属用户，持续高于阈值只通知一次，低于阈值后重新待发。StarRail-plugin 没有体力推送，聊天中不提供开启命令。
- 提醒状态跨重启保存，验证失败退避一天，账号移除/授权撤销/到期后暂停。发送结果不明确时不自动重复发送；进程恰在发送前崩溃可能漏一次通知。现有账号默认不启用提醒。

## 养成、材料与模拟

- “养成计算”读取官方当前等级，可选择角色、装备及技能/行迹目标，查询材料需求；聊天 `*角色名养成 [UID]`（`*角色名计算` 等价）计算升至上限。不会升级或扣除材料。当前支持等级 1–80。
- “材料与卡池”查询固定参考材料来源和历史期次，支持版本和国服日期筛选。聊天使用 `*名称材料`，名称是角色时按 Yunzai 发送米游社合集（小橙子啊等）中的角色培养素材图（`*符玄素材`、`*符玄突破`、`*符玄培养` 等价，`*更新符玄素材` 重新读取，开拓者回复暂无主角素材）；卡池按 miao-plugin 出图：`*3.2卡池`、`*3.2上半卡池` 列出该版本的卡池，`*角色或武器名卡池` 列出其出现过的卡池（`详情` 显示整个卡池），`*卡池` 为卡池帮助；固定快照未在线校准，不代表当前活动。
- “模拟抽卡”提供独立参考娱乐模型和模拟库存/历史，支持 `*十连[角色|光锥|常驻]`（`*抽卡` 同为十连）、`*模拟记录`、`*重置模拟 确认`。管理页可选择参考卡池、目标及每日额度。
- 模拟不使用 CK、不消耗真实货币、不写入 UIGF；不代表官方概率或保底规则。管理页和聊天档案分开，国服 04:00 重置额度，清空历史不返还当天已用次数；未知响应可重试同一请求避免重复模拟。

## 群内设置与主动参评

“群内设置”页面可编辑本游戏的群启停、图片/文本回复和群别名，并确认清空本地排行。群设置优先于全局，保存时校验版本；不同协议、机器人和群分别保存。聊天 `*群设置` 由群管理员、群主或超级管理员使用。

群成员在群内查看单个角色面板时，面板、遗器评分与默认伤害按 miao 的群排名自动记入本群（公开 UID 与昵称）。`*希儿排名` 按伤害排行，`*希儿遗器排名` 按评分排行，`*群排名` 列出各角色第一，`*最强希儿`、`*最高分希儿` 显示第一名的面板；超级管理员可 `*重置排名`，群管理员可 `*刷新排名`、`*关闭排名`、`*开启排名`。此功能不是全服排名，再次查看面板时更新；管理员也可在管理页清空本群排行。同 ark-plugin，页面宽 930（欢愉命途 960、记忆命途 1000），单个角色的伤害或遗器排行另加一栏 ark 给出的全服排名（默认把本群记录的面板发给 ark 计算），管理页“ark 扩展设置”可关闭或改查 ark 保存的各 UID 面板。

## 游戏签到与公共资料

“游戏签到”支持状态、当月奖励、单次领取和显式开启每日任务。聊天使用 `*签到 [UID]`、`*签到状态 [UID]`、`*自动签到 开启/关闭 [UID]`。自动任务默认北京时间 08:00、30 天、不主动通知；管理页可改时间、期限与私聊结果选项。验证码或首次绑定在官方应用处理；未确认的上游写入不反复重试。

“游戏查询”中的公共查询池入口或 `*公开信息 UID [区服]` 只查询目标公开基础资料，使用本人主动加入公共池且仍授权本游戏的账号，不会借用私人账号。账号所有者在账号插件本人私聊中设置用途与预算；没有可用账号/额度时明确提示。

## 云排名、面板与 UID 验证

“云排名与面板”使用 ark.ivny.cn 的匿名额度，支持额度、玩家角色排名、角色分布和自定义排名。自定义排名可按伤害/装备评分排序、组合两项星魂条件，前二十项可在五分钟内查看其公开云面板。服务匿名化 UID 时保持匿名，未知装备词条不补零。

查询前确认发送所填 UID、角色和筛选条件，不发送 CK 或 QQ。任务可取消；切换参数清除旧结果。“接收云端面板”要求先在原机器人主动上传，并在服务十分钟期限内接收，仅查看而不覆盖本地资料。

本人 OneBot11 私聊发送 `*云验证 获取 UID 确认`，再发送 `*云验证 进度` 获取验证码。将它设为游戏公开签名，生效后发送 `*云验证 提交 UID 确认`；`状态 UID 确认` 查询关联，`取消` 停止本地等待。获取会发送 UID，提交和状态会把本人的 QQ 与 UID 发给 ark，建立或查询跨机器人关联；不授予本地账号权限。取消不能撤销已提交的云操作。

聊天沿用 ark-plugin 的自定义排行：`*ark希儿排行 [筛选] [数量:N]`（`*ark希儿伤害排行` 同义，`*ark希儿圣遗物排行` 按遗器评分，写法同上游）列出 ark 收录的该角色面板全服前 N 名（1–50，默认 20），按 miao 的排行图出图，排名说明中写明全服数据、排序与筛选。所有人可按星魂筛选（列名同上游，如 `命=6`、`命座<=2`、`cons>0`）；等级、突破、行迹、光锥、伤害、评分、套装与部位主词条（如 `部位4=速度`、`部位3=暴击`）等其余列需超级管理员，且账号插件已配置 ark 令牌。`*ark自定义排行帮助` 按同样条件给出普通或高级说明。ark 返回的 UID 部分隐藏。五分钟内引用排行图片（或发起排行的那条命令）发送 `*ark获取面板N`（1–20）即按面板命令的样式查看第 N 名的面板，不记入群排名。超级管理员发送 `*arktoken用量` 查看 ark 令牌（未配置时为匿名请求）的剩余额度。聊天中的 ark 请求在账号插件配置了令牌时由其携带令牌代发，否则匿名发送。

同 ark-plugin 的面板排名，面板与伤害图在伤害表后加上 ark 的全服总伤害排名与圣遗物排名（上游在星铁中也这样称呼遗器评分的名次）：默认按“图表排名”显示“排名统计”，画出 ark 的伤害与圣遗物评分分布曲线并标出本面板的位置，下方写“位次 / 总数 (百分比%)”。管理页“ark 扩展设置”可关闭，或改为在伤害表中加一行伤害排名、圣遗物排名或两者，排名写法可选位次、百分比或两者；默认把本地面板发给 ark 计算名次（UID 以 ark 的 999999999 代替），关闭“按本地面板计算”后改查 ark 保存的该 UID 面板；“注明本地数据”在排名后注明（本地）或换装面板的（面板变换）。

同 ark-plugin，面板换装与 ark 重投识别的面板在每个伤害后标出相对该 UID 已保存面板同名伤害的变化（↑ 绿、↓ 红），伤害标题超过 20 字宽时截断；管理页可关闭变化或改为不处理、换行。

同 ark-plugin，`*更新面板` 在读取展柜之前先请 ark 更新发送者当前 UID 的云端面板（上游不等待回应，这里最多等五秒，因为账号插件只在事件进行中代发）。管理页“ark 扩展设置”开启“首次更新面板时自动从 ark 获取面板”后，当前 UID 还没有保存的面板时，先向 ark 请求该 UID 的面板（发送 QQ 与 UID，需先在 ark 验证过 UID，仅限 OneBot11），按导入面板数据的方式存入并回复“[ark-plugin]已自动从API获取N个数据”，随后照常读取展柜。

`*导出面板数据`、`*导入面板数据<UID>` 与 `*星铁导出面板` 的使用者按 ark 的设置限制，管理页“ark 扩展设置”可调整：导出面板数据默认允许绑定 CK 的用户与超级管理员，导入面板数据默认只允许超级管理员，导出面板文件默认允许绑定 CK 或已在 ark 验证 UID 的用户；均可改为任何人或禁用。面板换装识别截图（OCR）也可在此关闭。

私聊签名验证和交换接收已有合成验证，尚未替真人账号操作或验收。

## 开发与打包

工具链沿用 RayleaBot：Go 1.26.6、Node 26.7.0、pnpm 11.22.0。

```powershell
node scripts/prepare-ui.mjs
corepack pnpm --dir ui install --frozen-lockfile
go test ./...
corepack pnpm --dir ui test
corepack pnpm --dir ui run build
$env:RAYLEA_PLUGIN_BUILD_USE_WORKSPACE='1'
go run github.com/RayleaBot/RayleaBot/sdk/go/cmd/raylea-plugin build-go --backend ./cmd/plugin-starrail --target windows-x64 --include DATA_SOURCES.md=DATA_SOURCES.md --include .rayleabot/source.zip=ui/source.zip
```

打包前运行 `python scripts/bundle-artwork.py --references <参考项目/2026-09-15>`，把模板用到的上游图片、字体与资料文件从固定提交复制到 `assets/`（不纳入版本库，构建时随包分发），再运行 `python scripts/source-bundle.py` 生成管理页提供下载的源码包。源码包含本插件与相邻 RayleaBot 的 SDK 源码及 `go.work`，可按上述命令构建；SDK v0.7.1 发布前，独立检出仍需相邻的 RayleaBot 仓库。

另支持 `linux-x64` 和 `macos-arm64`。数据文件位于宿主提供的本插件数据目录内；抽卡记录属于非凭据业务数据，使用原子文件替换保存。

## 查询、历史与群榜

查询结果下可展开完整分组和记录，切换期次/月份后重新查询。月报查询页可保存指定月份、依次保存官方可用月份、累计已保存收入及删除月份。明细和本地历史每次读取重新检查角色授权。

群内“游戏提交挑战 玩法 [本期/上期] [UID]”主动公开本人成绩；“游戏挑战排行 玩法 [期次] [指标] [页码]”分区查看，“游戏退出挑战 [玩法]”删除本人参评。群管理页提供玩法筛选、重新排序和按期清理。“游戏挑战提醒 玩法 指标 阈值 [时间] [UID]”开启每日或每周（如“每周一20时”）的挑战目标检查，未达目标才私聊；“游戏挑战提醒状态”查看，“游戏关闭挑战提醒 [UID]”取消，不影响体力提醒。

卡池资料页支持角色/装备历史、版本和日期筛选及出现次数；抽卡明细页可按版本统计本地档案。资料来自固定快照，推定日期及未覆盖记录明确标记。

提醒页的“每日月报收集”可为所选角色开启有期限的每日保存，通知默认关闭。停止任务不删除已保存月报。超级管理员发送“*星琼任务”按 Yunzai 为所有已绑定账号保存本月及官方仍提供月份的开拓月历；一次未能完成时，再次发送会跳过一小时内已保存的账号继续。


## 云功能与交换档案

云页面可选择匿名或授权额度及高级条件；授权查询使用账号插件管理页“ark 授权令牌”中配置的令牌，由账号插件代发请求。OCR 只接收明确选择的 HTTPS 装备图片，随后可选本人角色进行换装模拟。

“面板交换档案”支持读取本人官方面板、导入旧 miao PlayerData、导出、十分钟上传/接收、导入面板排名及更新请求。官方显示值转换的强化档位属于近似还原。每次传输重新验证角色，导入来源单独保存。

长期云面板在本人 OneBot11 私聊使用 `*云面板 获取 UID 确认`，再用 `*云面板 进度`、`*云面板 保存` 或 `*云面板 取消`。此请求向 ark 发送真实聊天 QQ 与 UID；需要先完成云 UID 验证，保存还要求本人账号绑定同 UID，保存的角色与其他面板一样用面板命令查看。`#星铁导出面板` 同 ark-plugin，把当前 UID 已保存且来自官方的面板作为 miao 面板数据文件发送。


## 社区、兑换码与公开资料

“米游社任务”页提供账号级米游币和明确的社区操作，一次/每日任务可分别选择浏览、点赞和分享。所有定时任务默认关闭。

“兑换码与资产”页匿名读取官方前瞻代码；国服在游戏内兑换，已授权海外角色提供固定官方兑换接口。可分批保存官方当前可读的资产变化记录，按月与来源统计；这些数值不代表实际付款金额。

“公告与活动”页支持官方新闻分页、米游社搜索、文章全文分段及原图链接、国服活动日期。缺失活动时间保留原文，不把公告展示期限当作活动期限。群推送按 Yunzai 的米游社推送：群管理员发送 `*开启公告推送`、`*开启资讯推送`、`*开启到期活动推送` 开启（“开启”换成“关闭”停止），每五分钟向每个群推送两小时内的一条新帖（按上游屏蔽词过滤，同一帖十小时内不重复），按 mysNews 出图；每天十点后推送一天内结束的活动。超级管理员发送 `*推送公告`、`*推送资讯` 立即检查全部群。

“攻略与工具”页可选择并保存默认攻略来源、浏览合集和官方原图。未明确许可的外部攻略和图鉴素材不预装。

管理员发送 `*素材更新 star-rail-atlas` 下载 Atlas 星铁图鉴后，每条消息先按 Atlas 查找图鉴。Miao-Yunzai 把星铁前缀统一改写为 `#星铁`，Atlas 以优先级 10 排在 StarRail-plugin 的规则之后、miao 与 Yunzai 的规则之前，这里的顺序相同：StarRail-plugin 规则收下并结束的写法（如 `*希儿面板`、`*宇宙`、`*体力`、`*角色`、`*抽卡记录`）由对应命令回答，不再交给 Atlas；miao 先接走的角色资料写法（角色名后接图鉴、资料、天赋、行迹、星魂、照片等词，如 `*希儿图鉴`）也不交给 Atlas。各模块按 Atlas 的规则接收消息并去掉前缀与规则词：角色、光锥、遗器与敌人收带前缀或含“图鉴”的写法（如 `*希儿`、`*于夜色中`、`*过客套`、`于夜色中图鉴`），角色攻略收含“攻略0”“攻略”“指南”的写法，角色培养材料（库中有该模块时）收含“素材”“突破”“材料”“培养”的写法，这两类前缀可省（如 `希儿攻略`）。名称按图鉴库的别名换算；找到图片即发送，其余消息照常交给后续命令，如 `*希儿` 在库中没有该角色的图时才出角色卡片。StarRail-plugin 的攻略命令回答后仍把消息交给其他插件，因此 `*希儿攻略` 先发送米游社攻略，再发送 Atlas 的角色攻略图。图鉴库 `index/` 中的写法（如 `*光锥`、`*五星光锥`、`*毁灭光锥`、`*遗器`）回复 Atlas 的编号列表（各项以本插件的前缀写出），之后本人直接发送序号即按该项查找；列表按 Atlas 的计数失效：本人之后交给 Atlas 的每条消息计一次，选中的一项再计一次，选到结果时清零，计满四次时列表失效。Atlas 本意把列表合并转发、转发失败时出图，但 Miao-Yunzai 的 makeForwardMsg 只生成转发消息而不发送，上游因此总是出图；这里按本意合并转发，无法转发时按 Atlas 的列表页出图。

## 本地图库

“图库”页支持图片/目录批量导入、分类/角色关联、修改信息、预览、原图下载与删除。使用者须有对应素材许可。图片不做二次转换；上限为每张4 MiB、2400万像素，全库2000项、512 MiB。WebP按[公开容器规范](https://developers.google.com/speed/webp/docs/riff_container)读取尺寸，浏览器验证能否显示。

超级管理员可按 miao 发送 `*上传希儿照片`（图片随消息发送或引用图片消息）加入角色照片，`*上传希儿面板图` 加入面板图（面板随机使用，没有时用默认立绘；开拓者各命途按 miao 分穹、星两组共用面板图），`*删除希儿面板图1` 按 `*希儿面板图列表` 的序号删除；面板后发送“原图”取回面板所用的立绘。按 miao 直接发送角色名（如 `*希儿`、`*希儿卡片`，可带 UID）出角色卡片：照片与“照片”命令同一来源（miao 没有星铁的角色照片，因此主要取自图库，没有照片时同上游回复“暂无角色图片”），附当前 UID 该角色的等级、星魂、光锥、技能与遗器，其他命令与 Atlas 图鉴都不匹配时才生效；“原图”发送卡片所用的照片。发送“星铁照片 角色名”“星铁图鉴图 分类 [关键词]”读取图库，“星铁原图”重取当前聊天内十分钟内由本人查询的图片。


## 帮助与冲突设置

“帮助与版本”页及帮助/版本命令使用安装包同版本的命令声明；`*更新日志`、`*插件更新日志` 与上游一样所有人可用，回复插件与资料版本。自定义别名优先于内置名称，群别名优先于全局别名；管理页会列出覆盖了内置名称的别名。聊天中设置或删除全局别名的权限按 Yunzai 的别名设置权限，在查询设置中选择所有群员（默认）、群管理员或仅超级管理员，私聊中只有超级管理员可以设置。

国服与海外授权由账号插件区分，游戏侧仍使用同一服务；海外支持官方同步，国服完整逐抽限制保留。另提供基于已保存开拓力记录的在线窗口估算；估算不等于官方在线时长。
